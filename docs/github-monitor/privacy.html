GitHub Monitor privacy policy

Last updated: 9 November 2026

GitHub Monitor is a personal application operated by Bola Maged Ramses Nessim. Contact: bmaged23@gmail.com.

Information used

The application collects aggregate GitHub repository traffic, including daily views, clones, unique estimates, referring websites and popular repository paths. GitHub does not provide individual visitor identities through these traffic endpoints.

Google account access

The application requests the Gmail send permission to send traffic alerts to the operator's own email address, bmaged23@gmail.com. This permission is not used to read, search, modify or delete inbox messages. Google authorization credentials are used to authenticate these sending requests.

Storage and sharing

Credentials are stored in private local credential files and encrypted GitHub Actions secrets. Aggregate traffic baselines and unsent reports are stored in a private GitHub repository. Google processes outgoing messages for delivery, and GitHub hosts the workflow and private state. Information is not sold, used for advertising, or used to train AI models. This public documentation contains no account credentials or private traffic reports.

Retention and deletion

The baseline retains daily traffic high-water marks for up to 60 days; repository state, queued reports and historical GitHub revisions may remain until removed by the operator. Delivered emails follow the mailbox owner's retention choices. Local files may remain until deleted. The operator can disable the workflow, delete stored reports and credentials, and revoke access through Google Account third-party connections.

Google API data

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Permissions are used only to provide the described personal notification function.

For access or deletion requests, contact bmaged23@gmail.com.
