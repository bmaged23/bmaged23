GitHub Monitor

A personal application operated by Bola Maged Ramses Nessim. It checks aggregate traffic statistics for the operator's GitHub repositories and sends traffic-change notifications to the operator's Gmail address.

The application requests Gmail permission only to send email. It does not request permission to read inbox messages. GitHub statistics do not identify individual visitors.

This application is for the operator's personal use; it is not a public sign-up service.
